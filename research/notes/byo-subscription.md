# BYO AI subscription for the in-app "Ask" bar (as of 2026-11-15)

Goal: "log 2 eggs" / "did I keep my streak" typed in ycyc, answered by the user's own ChatGPT / Claude / Gemini / Grok plan calling ycyc's MCP tools, with ycyc paying no inference.

## TL;DR

- **Only OpenAI has an official "use your plan in my app" program:** Sign in with ChatGPT (SIWC) plan usage, launched at DevDay 2026-09-29. It's self-serve only for open-source and locally run apps. A paid or remotely hosted app needs OpenAI approval (interest form), and the documented redirect is loopback `127.0.0.1` only, so a mobile app can't ship it today without OpenAI's help.
- **Anthropic explicitly forbids it.** No Claude.ai login in third-party apps and no routing through Pro/Max credentials, enforced since Apr 4, 2026. The sanctioned routes are API keys, a remote MCP connector inside the user's own Claude app, or the unmodified Claude Code binary signed in by the user.
- **Google has no program and banned accounts that reused Antigravity / Gemini CLI OAuth** (Feb 2026). **xAI** has a SuperGrok device-code OAuth that Kilo, Hermes, Warp, OpenClaw and Agno use, but I found no official xAI developer doc, it's allowlisted, and it's flaky.
- **The sanctioned, zero-cost, ships-today path is a handoff:** the Ask bar opens the user's own assistant with the prompt prefilled, and the assistant calls ycyc through the MCP connector the user already added. `chatgpt.com/?q=`, `claude.ai/new?...` and `grok.com/?q=` are all iOS universal links into the native apps (verified from each domain's apple-app-site-association file, fetched 2026-11-15).

## No-auth fallback: prefilled deep links (iOS universal links checked 2026-11-15)

From each domain's `/.well-known/apple-app-site-association`:

| Target | URL | Opens native iOS app? | Notes |
|---|---|---|---|
| ChatGPT | `https://chatgpt.com/?q=<urlencoded>` (alias `?prompt=`) | **Yes.** AASA lists `/` with `?q=`, `?prompt=`, `?hints=`, `?mode=` for `com.openai.chat` | `?q=` isn't officially documented ([community note](https://community.openai.com/t/onboarding-users-with-custom-prompts/1388102)). Whether it auto-sends varies by report, so test in the app. Add `?no_universal_links=1` to force the browser. |
| Claude | `https://claude.ai/new?q=<urlencoded>` (desktop scheme `claude://claude.ai/new?q=`) | **Yes.** AASA lists `/new` for `com.anthropic.claude` | `q` prefills and the user taps send. Truncated at about 14,000 chars ([Anthropic support, updated 2026-06-30](https://support.claude.com/en/articles/14729294-open-claude-desktop-with-a-link)). The mobile link article only documents Code routes ([updated 2026-05-06](https://support.claude.com/en/articles/14898120-open-the-claude-mobile-app-with-a-link)), so test `new?q=` in the iOS app. |
| Grok | `https://grok.com/?q=<urlencoded>` | **Yes.** AASA claims `/*` for `ai.x.GrokApp` (minus billing/auth paths) | `?q=` is community-reported, not documented ([PopClip ext](https://www.popclip.app/extensions/x/j2wxmc)). Test it. |
| Gemini | `https://gemini.google.com/app?q=` | **No.** AASA only claims `/app/*` with `target=agent/spark` or `thread_id` | Prefill isn't native. Chrome extensions exist just to add it. Treat Gemini as unsupported. |

Always copy the prompt to the clipboard before opening, so a dropped prefill costs one paste. URL limits don't matter for Ask-bar prompts (keep under ~2k chars).

## ToS risk

| Option | Risk to the end user's account | Risk to ycyc |
|---|---|---|
| Handoff deep link + MCP connector | None. First-party features used as designed. | None. Prefill params are undocumented (ChatGPT/Grok) and can break silently, so keep the clipboard fallback. |
| SIWC plan usage, approved | None | Low. A preview program with changing limits and an approval gate. |
| SIWC plan usage, unapproved in a hosted/paid app | Low (OpenAI shows the app by name and the user can revoke) | Medium. Outside the published eligibility, and OpenAI can revoke the client. |
| Codex CLI OAuth reuse | Low to medium | Medium to high. Client spoofing, explicitly not the plan-usage endpoint, can break any day. |
| Claude Pro/Max OAuth in ycyc | **High.** Anthropic enforces "without prior notice", and tokens have been blocked since Apr 4, 2026 ([Engadget](https://engadget.com/ai/its-no-longer-free-to-use-claude-through-third-party-tools-like-openclaw-160912082.html)) | **High.** Legal demands went to OpenCode in Mar 2026, which removed Anthropic OAuth citing "anthropic legal requests" ([The Register, 2026-02-20](https://www.theregister.com/2026/02/20/anthropic_clarifies_ban_third_party_claude_access), [falcao.org](https://falcao.org/posts/anthropic-claude-access-crackdown-ecosystem-fallout/)) |
| Gemini consumer OAuth reuse | **High.** Whole Google accounts restricted in Feb 2026 | High |
| xAI SuperGrok OAuth | Low to medium (unclear terms) | Medium. Allowlist, no published program. |
| BYO API keys (any provider) | None | Low. ycyc must store keys securely server side. |

## Recommendation

**Today (demo):** the handoff Ask bar. ycyc composes the prompt, copies it, and opens `claude.ai/new?q=` / `chatgpt.com/?q=` / `grok.com/?q=`. The assistant calls ycyc's MCP tools on the user's own plan, and the Convex-reactive activity feed shows the call when the user comes back. Zero inference cost, zero registration, fully sanctioned. Claude is the safest demo target.

**After the hackathon:**
1. Make the connector the product: one-tap setup links (Claude `customize/connectors?modal=add-custom-connector`, ChatGPT plugins page on web), then get listed in the Claude connector directory and submitted as a public ChatGPT plugin, so no developer settings are needed.
2. Submit the SIWC interest form now (ycyc's repo is public, which helps). If approved, ship an in-app Ask bar on ChatGPT Plus/Pro via the Responses API with ycyc tools as function tools, and work with OpenAI on a mobile redirect (an https/app-link callback instead of loopback).
3. Ask xAI directly about SuperGrok OAuth for third parties. Don't touch Claude or Gemini consumer OAuth. Offer BYO API key as the power-user fallback.

Side note: `src/components/assistant-guide.tsx` still describes ChatGPT's old "Developer mode > Connectors" flow. Current docs say chatgpt.com/plugins > + > Add custom MCP server > Create as a plugin > Install, then `@ycyc` in chat.
